# 项目概况 (Project Overview)

## 1. 项目简介
**ATMQuant** 是一个基于 `vnpy 4.1` 的开源 AI 量化交易框架，专注于图表可视化与策略研发。
它在 `vnpy` 的基础上进行了深度的本地化修改和功能增强，特别是针对多周期图表分析、技术指标计算和策略开发流程进行了优化。

## 2. 核心特性
- **多周期图表系统**: 支持双图/四图视图，实现多时间框架（如 5分钟、15分钟、1小时、日线）的对比分析与智能同步。
- **增强型指标库**: 内置 BOLL, SMA, EMA, MACD, RSI, DMI 等常用指标，支持动态加载与模块化管理。
- **策略开发框架**: 提供标准化的策略基类 (`BaseCtaStrategy`)，集成了日志、告警和生命周期管理。
- **配置管理**: 基于 `.env` 的轻量级配置系统，支持环境隔离。
- **数据处理**: 集成 `akshare` 数据源，支持期货数据的定时下载与清洗。

## 3. 技术架构

### 3.1 核心技术栈
- **语言**: Python 3.10+
- **基础框架**: `vnpy 4.1` (包含本地核心修改 `vnpy/`)
- **GUI 框架**: `PySide6` (Qt for Python)
- **数据处理**: `numpy`, `pandas`, `ta-lib`
- **数据库**: MySQL (`sqlalchemy`, `pymysql`)
- **日志监控**: `loguru` (日志), 飞书/钉钉机器人 (告警)

### 3.2 目录结构概览
- **`core/`**: 核心业务逻辑，包含图表组件、指标实现、数据处理、日志系统和策略基类。
- **`vnpy/`**: 本地修改版的 VeighNa 框架核心，Agent 在开发时需优先参考此目录下的实现。
- **`config/`**: 统一配置管理，包含交易时段、告警配置等。
- **`strategies/`**: 用户策略存放目录。
- **`backtests/`**: 回测脚本与配置。
- **`documents/`**: 项目文档中心。

## 4. 开发环境
- **依赖管理**: `requirements.txt`
- **测试框架**: `pytest` (单元测试与集成测试)
- **代码规范**: PEP 8，强制中文文档字符串。
